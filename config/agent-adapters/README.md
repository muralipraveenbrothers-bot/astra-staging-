# Agent adapter snippets

These files are generated by `POST /api/ai/adapters/apply` (`confirm: true`)
after the Central AI Adapter discovers a model whose **runtime** context
window is ≥ Hermes' 64K minimum.

They are not brains. Every file points at `http://127.0.0.1:3000/v1`.

| File | Consumed by |
|---|---|
| `hermes-astra-provider.yaml` | Hermes `config.yaml` custom provider |
| `openclaw-astra-provider.json` | OpenClaw `models.providers.astra` |
| `paperclip-astra.env` | Paperclip `OPENAI_BASE_URL` |
| `n8n-astra-http.json` | n8n HTTP Request workflow |
| `langgraph-astra.json` | In-process LangGraph LLM pointer |
| `openhands-astra.json` | OpenHands approval-executor → Astra /v1 |
| `agentzero-astra.json` | Agent Zero multi-agent orchestration → Astra /v1 |

The Manus cloud adapter (`manus-cloud.json`) has been removed — the Manus
executor was replaced by OpenHands (approval-executor) and Agent Zero
(multi-agent-orchestration). See `config/astra.json` and
`scripts/setup-executors.cmd`.

Do not point these tools at Ollama `qwen3:14b` unless `/api/show` (or `/api/tags` `details.context_length`) reports ≥ 64000 **and** the model is actually installed.
